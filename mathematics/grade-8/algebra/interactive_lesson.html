📌 Формули скороченого множення (завжди перед очима)
(a + b)² = a² + 2ab + b²
(a − b)² = a² − 2ab + b²
a² − b² = (a − b)(a + b)
a³ + b³ = (a + b)(a² − ab + b²)
a³ − b³ = (a − b)(a² + ab + b²)
b − a = −(a − b)
a² + 2ab + b² = (a + b)²
a² − 2ab + b² = (a − b)²
