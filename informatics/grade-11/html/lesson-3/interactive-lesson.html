Оцінювання практичної роботи (приклад): три сторінки з правильною структурою — 3 бали; список не менше ніж із трьох пунктів — 2 бали; таблиця з назвою, заголовками й даними — 3 бали; працюють усі посилання й зображення — 2 бали; код без помилок вкладеності — 2 бали.

Кнопка «Aa» збільшує текст для великого екрана, «⛶» — повноекранний режим, клавіші ← → перемикають розділи. Прогрес зберігається в браузері.

Запитання для самоперевірки

    
1. Чим відрізняються ul та ol?
ul — маркований список (порядок неважливий), ol — нумерований (порядок важливий).

    
2. Для чого потрібен тег li?
Створює окремий пункт списку; розташовується лише всередині ul або ol.

    
3. Яку роль виконують tr, th і td?
tr — рядок таблиці, th — заголовкова комірка, td — комірка з даними.

    
4. Чим семантичні елементи корисні для структури сторінки?
Вони показують роль частин сторінки (шапка, меню, основний вміст, підвал), роблять код зрозумілішим і допомагають браузерам та пошуковим системам.
