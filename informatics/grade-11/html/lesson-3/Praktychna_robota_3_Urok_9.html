ПРАКТИЧНА РОБОТА № 3

Створення структурованої вебсторінки засобами HTML

Урок 9

Мета: На основі власного проєкту створити сайт із кількох сторінок: оновити головну сторінку, створити сторінки «Про сайт» і «Корисна інформація», додати списки й таблицю, з’єднати сторінки посиланнями та перевірити результат у браузері.

Проєкт «Мій сайт: від ідеї до вебсторінки»

Ви вже створили каркас головної сторінки (практична робота № 1) і додали зображення та гіперпосилання (урок 7). Сьогодні ваш сайт стане багатосторінковим: на основі файлу index.html ви створите ще дві сторінки й наповните їх змістом. Тема залишається тією, яку ви обрали раніше. Оформлення (кольори, шрифти, відступи) ми додамо пізніше за допомогою CSS.

Що потрібно мати: папку my-site з файлом index.html, зображення з папки images, відкритий проєкт у VS Code та браузер. Після кожної зміни зберігайте файл (Ctrl + S) і оновлюйте сторінку в браузері (F5).

Завдання 1. Сплануйте сайт із трьох сторінок

Заповніть таблицю перед написанням коду. Використовуйте свою тему.

Частина сайтуМій варіант
Назва сайту
Головна (index.html): список із трьох пунктів «Що ви знайдете на сайті»
Про сайт (about.html): три цілі сайту (нумерований список)
Корисна інформація (info.html): назва таблиці
Заголовки трьох стовпців таблиці
Три рядки даних для таблиці (по одному слову або короткій фразі на стовпець)
Яке зображення буде на сторінці (назва файлу в папці images)

Завдання 2. Перевірте структуру проєкту

Переконайтеся, що у папці my-site є файл index.html і папка images із зображенням. Після виконання роботи проєкт матиме таку структуру:

my-site/
├── index.html
├── about.html
├── info.html
└── images/
    └── photo.jpg

Завдання 3. Оновіть головну сторінку (index.html)

  1. Відкрийте my-site/index.html у VS Code.
  2. Перевірте каркас: DOCTYPE, <html lang="uk">, meta, title (назва вашого сайту), блоки header, nav, main, footer.
  3. Замініть меню nav на список із трьох посилань:
<nav>
  <ul>
    <li><a href="index.html">Головна</a></li>
    <li><a href="about.html">Про сайт</a></li>
    <li><a href="info.html">Корисна інформація</a></li>
  </ul>
</nav>

Сторінок about.html та info.html ще немає — ви створите їх у наступних завданнях.

4. Замініть вміст main: вступ із 2–3 реченнями та зображенням і розділ зі списком щонайменше з трьох пунктів. Замініть текст-зразок власним:

<main>
  <section>
    <h2>Вступ до теми</h2>
    <p>Напишіть 2–3 речення про обрану тему.</p>
    <img src="images/photo.jpg" alt="Опис зображення">
  </section>
  <section>
    <h2>Що ви знайдете на сайті</h2>
    <ul>
      <li>Перший пункт</li>
      <li>Другий пункт</li>
      <li>Третій пункт</li>
    </ul>
  </section>
</main>

Примітка: пункти меню матимуть маркери — так і має бути. Прибирати їх та розташовувати пункти в рядок ви навчитеся за допомогою CSS.

Завдання 4. Створіть сторінку «Про сайт» (about.html)

  1. Зробіть копію файлу index.html: у панелі файлів VS Code натисніть Ctrl + C, потім Ctrl + V, перейменуйте копію на about.html. (Або виконайте File → Save As…)
  2. Змініть <title>, наприклад: «Про сайт — Назва сайту». Шапку header, меню nav і підвал footer залиште без змін.
  3. Замініть вміст main на шаблон:
<main>
  <article>
    <h2>Про сайт</h2>
    <p>Цей сайт створено для ... Він розповідає про ...</p>
    <h3>Мета сайту</h3>
    <ol>
      <li>Розповісти про ...</li>
      <li>Показати ...</li>
      <li>Допомогти ...</li>
    </ol>
  </article>
  <section>
    <h2>Про автора</h2>
    <p>Мене звати ... Я навчаюся в ... класі.</p>
  </section>
</main>
  1. Замініть крапки на власний текст. Виділіть одне важливе слово тегом <strong>.

Підказка: розповідь про сайт має сенс і без решти сторінки, тому її розміщують в article. А «Про автора» — це тематичний розділ, тому section.

Завдання 5. Створіть сторінку з таблицею (info.html)

  1. Скопіюйте index.html ще раз і назвіть копію info.html.
  2. Змініть <title> («Корисна інформація — Назва сайту»). Шапку, меню й підвал залиште.
  3. Замініть вміст main на шаблон:
<main>
  <section>
    <h2>Корисна інформація</h2>
    <p>У таблиці зібрано ...</p>
    <table>
      <caption>Назва таблиці</caption>
      <tr>
        <th>Назва</th>
        <th>Категорія</th>
        <th>Опис</th>
      </tr>
      <tr>
        <td>Приклад 1</td>
        <td>Категорія А</td>
        <td>Короткий опис</td>
      </tr>
      <tr>
        <td>Приклад 2</td>
        <td>Категорія Б</td>
        <td>Короткий опис</td>
      </tr>
      <tr>
        <td>Приклад 3</td>
        <td>Категорія А</td>
        <td>Короткий опис</td>
      </tr>
    </table>
  </section>
  <section>
    <h2>Поради</h2>
    <ol>
      <li>Перша порада</li>
      <li>Друга порада</li>
      <li>Третя порада</li>
    </ol>
  </section>
</main>
  1. Замініть назву таблиці, заголовки стовпців і дані на свої (ідеї — у вашому плані із завдання 1).
  2. У таблиці мають бути назва, заголовки та щонайменше три рядки з даними.
  3. Замініть поради на власні (нумерований список із трьох пунктів).

Примітка: без CSS таблиця відображається без рамок — це нормально. Головне, щоб дані стояли у своїх рядках і стовпцях.

Завдання 6. З’єднайте сторінки та перевірте сайт у браузері

  1. Переконайтеся, що меню nav із трьома посиланнями однакове на всіх трьох сторінках.
  2. Замініть підвал на всіх сторінках, щоб у ньому було посилання на головну:
<footer>
  <p><a href="index.html">На головну</a></p>
  <p>Навчальний проєкт. 11 клас.</p>
</footer>
  1. Додайте зображення з атрибутом alt хоча б на одну сторінку, крім головної (шлях images/назва.jpg).
  2. Відкрийте index.html у браузері та пройдіть усіма посиланнями: Головна → Про сайт → Корисна інформація → Головна.
  3. Якщо зміни не відображаються, збережіть файл і оновіть сторінку.

Якщо щось не працює

ПроблемаЩо перевірити
Посилання не відкриваєтьсяНазва файлу в href збігається з назвою файлу (з розширенням .html); файл лежить в тій самій папці.
Немає зображенняШлях і розширення (.jpg, .png, .webp) збігаються з назвою файлу в папці images.
Список виглядає як звичайний текстКожен пункт у <li>, а всі пункти — у <ul> або <ol>.
Таблиця «розсипалась»Комірки td/th — усередині <tr>, а рядки — усередині <table>.
Сторінка відображається неправильноКожен відкритий тег має закривальний; перевірте вкладеність і правопис тегів.

Чекліст самоперевірки

Додаткові завдання

  • Додайте до одного з розділів вкладений список (список усередині пункту li).
  • Відокремте розділи сторінки тегом <hr>, а в адресі чи вірші використайте <br>.
  • Об’єднайте дві комірки заголовка таблиці атрибутом colspan="2".
  • Додайте посилання на розділ сторінки: <a href="#contacts"> та id="contacts".
  • Поясніть призначення <caption>, <tr>, <th>, <td>, <article>.
  • Виправте помилку: <ul><li>Музика</li> Книги </ul>.

Домашнє завдання

  1. Завершіть наповнення всіх трьох сторінок: щонайменше два абзаци на кожній.
  2. Перевірте наявність назви, опису, розділів, списків і таблиці. Виправте помилки.
  3. Підготуйте 1–2 тематичні зображення, які дозволено використовувати, і збережіть посилання на джерело.
  4. Наступного разу ми оформлюватимемо сайт за допомогою CSS — принесіть проєкт у папці my-site.
