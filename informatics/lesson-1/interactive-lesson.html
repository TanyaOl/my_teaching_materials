Скрипт — програма для спрайта.
Проєкт — набір скриптів, що розв’язує задачу.

2. Сцена та її координати

Початок координат (0, 0) — центр сцени.
x: від −240 до 240 (ліво–право) · y: від −180 до 180 (низ–верх)
Вправо й угору — «+», вліво й униз — «−».

Задайте координати й подивіться, куди піде спрайт:

x: y:
🐱

x: 0 y: 0

3. Групи команд для дій над об’єктом

Рух (синій):
перемістити в x: y: — миттєво
ковзати … сек до x: y: — плавно
повернути в напрямку 90
змінити x на … змінити y на …
Вигляд (фіолетовий):
говорити Привіт! 2 сек змінити образ на … показати / сховати
Керування (жовтий):
коли ⚑ натиснуто чекати … секунд зупинити цей скрипт

4. Напрямок руху

0 — угору · 90 — вправо · 180 — вниз · −90 — вліво

Оберіть напрямок:

➡️

повернути в напрямку 90

Де опиниться кіт у кінці? Обери відповідь — і подивись, як це відбувається на сцені.

6. Міні-тест

👀 Гімнастика для очей: «Лови кота!»

Сядь рівно, голову не повертай — стеж лише очима за котом. Кіт ковзає по точках сцени, а внизу показано команду.
🐱

7. Практична робота «Виступ артистки»

▶ Відкрити Скретч ↗
Підручник, с. 119–120, завдання 7. У класі робимо за моделлю 1.
Порядок виконання
  1. Прочитайте сценарій: артистка з’являється на сцені, вітається, іде зі сцени.
  2. Змініть тло: Обрати тло → група Музика → Spotlight.
  3. Замініть спрайт: Обрати спрайт → Танцювальна музика → Ballerina; дайте їй власне ім’я.
  4. Видаліть спрайт Рудий кіт у полі спрайтів.
  5. Складіть скрипт за зразком (праворуч).
  6. Перевірте роботу програми (⚑).
Скрипт (модель 1)
коли ⚑ натиснуто
перемістити в x: −260 y: 0
ковзати 0 сек до x: 0 y: 0
говорити Привіт! 2 сек
повернути в напрямку 90
ковзати 1 сек до x: 260 y: 0
зупинити цей скрипт

🏠 Домашнє завдання

1. Прочитати §22 (с. 115–118).
2. Закінчити практичну роботу за моделлю 2: після привітання артистка не йде вперед, а повертається назад.
Підказка: потрібна команда «повернути в напрямку −90» і рух до x: −260.
3. Надіслати виконану роботу в Teams: у Скретч Файл → Зберегти на свій комп’ютер, потім прикріпити файл до завдання в Teams.
4. Завдання 10 «Інтелектуальна хвилинка» (с. 120): розмістити спрайти в клітинках квадрата так, щоб на кожній горизонталі, вертикалі та діагоналі були різні спрайти.
Підсумок уроку: координати (x, y) → перемістити / ковзати · напрямок → повернути · вигляд → говорити.
