RGB — колір на екрані

R
G
B
 · 
Адитивна модель
колір = суміш червоного, зеленого і синього світла. Для екрана.
Канал: 8 бітів
значення від 0 до 255. 0, 0, 0 — чорний, 255, 255, 255 — білий.
3 × 8 = 24 біти — True Color, 256³ = 16 777 216 кольорів.

CMYK — колір на папері

C
M
Y
K
у RGB:
Субтрактивна модель
фарби поглинають світло, ми бачимо відбите. Для друку.
C, M, Y — доповнення RGB
C = блакитний 0, 255, 255
M = пурпуровий 255, 0, 255
Y = жовтий 255, 255, 0
У кожному два канали по 255, третій 0.
K — чорна фарба (blacK): суміш C+M+Y не дає глибокого чорного.

HSL — колір, як його бачить око

H
S
L
у RGB:
H — тон (hue)
кут на колі, 0–360°: R 0° · Y 60° · G 120° · C 180° · B 240° · M 300°
S — насиченість
0 % — сірий, 100 % — чистий колір
L — світлість
0 % — чорний, 100 % — білий. Схожа модель — HSB (яскравість)

HEX і «Колірна лабораторія»

HEX — це RGB у шістнадцятковій системі: #FF A5 00 → FF = 255, A5 = 10·16 + 5 = 165, 00 = 0.
Змінюй число в будь-якій моделі — решта перерахуються. Колір той самий, а записи різні.

Практична робота № 3 · векторний редактор

09:00
Що робити (за підручником)
  1. Намалюй правильний трикутник (Вставлення → Фігури), Контур → Без контуру.
  2. Скопіюй його двічі. Заливка → Інші кольори → RGB: червоний, зелений, синій (один канал 255, решта 0).
  3. Модель HSL: запиши H для R, G, B у таблицю картки.
  4. Ще три копії: блакитний, пурпуровий, жовтий (в RGB два канали 255, третій 0); запиши H.
  5. Розташуй 6 трикутників у ряд за кольорами веселки; підпиши R, G, B, C, M, Y.
  6. Додай помаранчевий трикутник (255, 165, 0); запиши RGB і H.
  7. Збережи файл.
Не встигаєш? Спочатку R, G, B і помаранчевий. Коди й HEX — у «Колірній лабораторії» на картці.
⚠ Правила безпеки (БЖД)
  • Сиди прямо; відстань до екрана 50–70 см.
  • Не торкайся кабелів, розеток, роз’ємів.
  • Не вмикай і не вимикай техніку без дозволу вчителя.
  • Не їж і не пий біля комп’ютера.
  • Про несправність чи дивний запах — одразу скажи вчителю.
  • Роби паузи для очей: дивись у далечінь.

R, G, B: один канал 255, два інші 0. H = 0°, 120°, 240°.
C, M, Y: два канали 255, третій 0. H = 180°, 300°, 60°.
Помаранчевий: H = 39°. Між червоним (0°) і жовтим (60°).
Ряд за веселкою: R → Y → G → C → B → M (за зростанням H).

Підбиваємо підсумки

1
Назви колірні моделі для опису кольору.
Адитивна RGB; субтрактивна CMY/CMYK; перцепційні Lab, HSB, HSL. HEX — запис RGB.
2
Який принцип кодування кольору в RGB і CMYK?
RGB: світло екрана, 3 канали по 8 бітів. CMYK: фарби на папері, частки C, M, Y, K у %.
Один колір — різні записи. Модель обирають за призначенням: екран — RGB, друк — CMYK, налаштування — HSL.
