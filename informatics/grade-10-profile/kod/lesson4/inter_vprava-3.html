Інтерактивні вправи: кодування графічних зображень

Три вправи для закріплення. Відповіді перевіряються одразу, число спроб необмежене. Працює без інтернету.

Вправа 1. Растр чи вектор?

Для кожного об’єкта обери, як його краще зберігати: растром (пікселі) чи вектором (формули примітивів).

Відповідь вчителя: растр — фото з екскурсії, скан документа, скріншот екрана, фрагмент картини художника; вектор — логотип школи, схема електричного кола, креслення деталі, значок для інтерфейсу.

Вправа 2. Обчисли обсяг

Нове завдання щоразу випадкове. Вибери тип завдання, обчисли й введи відповіді.

Вправа 3. Знайди помилку у розрахунку

Учень розв’язав задачу. Обери рядок, у якому допущено помилку.
